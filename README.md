# ShadowFox Python Programming & Data Analysis Tasks

Overview

This repository contains work for the ShadowFox Python assignment shown in the provided task document. It progresses from Python fundamentals to practical programming and finally to exploratory data analysis (EDA) in Jupyter Notebook.

Assignment Levels

Beginner — Do 5 out of 9

The provided pages include:

Variables

Store 22/7 in pi and inspect its type.

Understand why for cannot be a variable name.

Calculate Simple Interest using principal, rate, and time.

Numbers

Practice format() and string representation.

Calculate circular pond area and water quantity.

Calculate speed from distance and time.

Lists

Manipulate a Justice League list.

Practice len(), append(), remove(), insert(), replacement, and sort().

Display the list after each operation.

If Condition

Calculate and classify BMI from user input.

Identify the country of a city from predefined lists.

Check whether two cities belong to the same country.

For Loop

Simulate dice rolls and count required statistics.

Simulate a 100-jumping-jack workout with user interaction.

Intermediate — Do Both

Web Scraper: Extract permitted public webpage data using Beautiful Soup or Scrapy.

Hangman: Build an interactive word-guessing game with hints and visual progress.

Advanced — Final Project

Create a Jupyter Notebook from scratch and perform data analysis on a selected dataset.

Advanced Project Workflow

Select a public dataset.

Load and explore it in Jupyter.

Inspect columns, types, missing values, duplicates, and statistics.

Clean the data where necessary.

Define a focused research question.

Analyze the data using Python.

Create relevant visualizations.

Explain the findings.

State limitations and a conclusion.
